# 数据说明

账目、会议收藏和凭证默认在手机应用私有目录保存；无需账户，不向原网站或 GitHub 上传。没有广告、分析或崩溃上报 SDK。

设置中心可选择“记录支出时同时保存到相册”，新用户默认开启，可随时关闭；更新保留已有开关选择。开启后，仅在账目保存成功后，将该笔账目的凭证照片额外复制到 `Pictures/SFO Travel`。包括拍摄和选择的凭证，均保存处理后的 JPEG 副本；取消记账不会创建相册副本。相册保存失败会提示单独重试，不撤销账目。

Android 10 及以上通过 MediaStore 写入应用创建的照片，不申请读取整个相册的权限。Android 6–9 在首次写入时按需申请 `WRITE_EXTERNAL_STORAGE`（权限声明限 API 28 及以下）。拒绝权限仍可记账、保存私有凭证。选择照片使用系统文件选择器，不扫描用户相册。

相册副本可被其他获授权的相册应用读取，也可能被系统相册的云同步功能上传。删除账目、关闭开关、卸载或清除应用数据都不会删除已导出的相册副本；请在相册中自行管理。

时钟城市、相册开关、语言和主题保存在本机，不读取位置。城市设置只调整顶部世界时钟及日差基准；天气和行程内容仍针对旧金山。加密备份包含账目、私有凭证和收藏，不包含这些设备偏好或相册副本。

首次使用设置 4–128 个字符的解锁密码；更新后的首次打开需验证，同版本再次打开无需重复输入。密码校验信息仅存于 Android 私有 SharedPreferences，使用随机盐和 600,000 次 PBKDF2-SHA-256，不保存或上传明文密码。连续输错会短暂限制重试，不删除账目、凭证或收藏；密码设置损坏时保持锁定，不自动重置。设置中修改密码需要当前密码。

这是应用入口保护，SQLite 和私有凭证未额外加密，依赖 Android 沙箱和设备存储保护；不提供每次启动或离开应用即锁定的功能。新备份直接使用应用解锁密码进行 AES-256-GCM 加密，不再设置独立备份密码。密码在设置、解锁或验证后仅保留于当前 WebView 会话内存，关闭进程或重载后不保留明文；同版本免密打开后，首次备份操作需验证一次当前应用密码。密码本身不包含在备份中，也无法在线找回。修改密码需要旧密码，成功后新备份使用新密码；已导出的旧备份仍需创建时的密码，恢复时可以选择旧备份密码且不改变当前应用密码。忘记密码时请保留应用及数据；已有加密备份可在其他设备用备份密码恢复。完整备份有密码加密，CSV 为明文。

公开数据更新请求 Open-Meteo、招商银行、欧洲央行和 Microsoft，服务方会看到普通网络连接信息（如 IP）。天气用固定旧金山坐标，不读取 GPS。请求不附带账目、照片或用户身份。

地图、官方详情和 GitHub 链接通过外部浏览器打开，适用目标网站政策。相机仅在主动拍摄时使用；导出仅在主动操作时将文件交给 Android 分享面板。

点击“检查更新”时连接 GitHub Releases；下载的 APK 暂存在应用私有缓存，不需要读取相册或公共存储。下载会核验 SHA-256，安装前核验包名、签名和版本。Android 8 及以上仅在用户点击安装时引导允许本应用安装未知应用，用户仍需在系统安装器中确认。没有后台静默更新。更新请求不携带账目或凭证。

Android 自动云备份和设备迁移关闭。手动备份保存位置由用户选择。卸载或清除数据会删除数据库和照片，应将备份保存到应用之外并保管密码。

为让 Android 接收文件的应用能完成读取，导出文件会暂存在本机私有缓存。下次导出会清理超过 24 小时的导出缓存；系统也可能自行清理缓存。它们不作为正式备份保留。

删除账目会删除数据库引用并尝试清理照片，异常中断可能留下孤立文件；卸载/清除数据会清理整个目录。

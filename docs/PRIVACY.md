# 数据说明

账目、会议收藏和凭证只在手机应用私有目录保存；无需账户，不向原网站或 GitHub 上传。没有广告、分析或崩溃上报 SDK。

SQLite 未额外加密，依赖 Android 沙箱和设备存储保护。应用无独立应用锁。完整备份有密码加密，CSV 为明文。

公开数据更新请求 Open-Meteo、招商银行、欧洲央行和 Microsoft，服务方会看到普通网络连接信息（如 IP）。天气用固定旧金山坐标，不读取 GPS。请求不附带账目、照片或用户身份。

地图、官方详情和 GitHub 链接通过外部浏览器打开，适用目标网站政策。相机仅在主动拍摄时使用；导出仅在主动操作时将文件交给 Android 分享面板。

Android 自动云备份和设备迁移关闭。手动备份保存位置由用户选择。卸载或清除数据会删除数据库和照片，应将备份保存到应用之外并保管密码。

为让 Android 接收文件的应用能完成读取，导出文件会暂存在本机私有缓存。下次导出会清理超过 24 小时的导出缓存；系统也可能自行清理缓存。它们不作为正式备份保留。

删除账目会删除数据库引用并尝试清理照片，异常中断可能留下孤立文件；卸载/清除数据会清理整个目录。

# 1.3.4b 测试版

此文档保留 1.3.4b 测试阶段的说明。当时仅在 beta/1.3.4b-ux 分支构建测试包，未创建 GitHub Release 或标签；测试验收后，相关改进随正式版 1.4.0 合并 main。

测试包 SFOBusinessTravel-v1.3.4b.apk 使用现有正式包名和固定签名，Android versionCode 仍为 1003004，可覆盖 v1.3.4；显示版本号为 1.3.4b，未来更高正式版可以正常更新。此包不会出现在应用内的正式版更新列表。密码校验同时识别测试后缀，覆盖测试版后输入原密码解锁，不重设密码或删除记录。

构建工具使用合法的 npm 版本 `1.3.4-b`，Vite 与安卓版本名称统一显示为 `1.3.4b`。

## 测试重点

- 普通记账金额为空，小费 0；计算器明确点击记入账本时才携带数值。
- 编辑金额、币种、分类、日期、备注和凭证；编号、创建时间及历史汇率保持，文件替换失败时保留旧凭证。
- 草稿在本机 SQLite 与浏览器预览独立存储，包含临时凭证；关闭可继续、暂存或放弃，重启可恢复。草稿不写相册、不包含在正式账目备份中。
- 紧凑账本与会议页、分组设置和增大的触摸区域；应用仍保持竖屏。
- 下载进度、取消、重试和错误解释；网络任务使用独立线程，取消请求不会被下载占用的 Capacitor 队列阻塞。
- 备份通过 Android 文件保存选择器，写入成功后才记录确认保存时间；取消不算成功。每 7 天提醒可关闭或推迟。

请在保留数据的情况下覆盖测试，不需要卸载。浏览器测试不能替代三星真机的键盘、系统文件保存器、相册和安装器体验。

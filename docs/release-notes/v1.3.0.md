# SFOBusinessTravel v1.3.0

- 首次打开设置解锁密码；以后更新应用，输入密码即可继续使用原有账目、照片和收藏，无需反复导出恢复。
- 输错或暂不输入只保持锁定，绝不主动删除记录。连续输错会短暂限制重试。
- 同版本再次打开无需重复输入。设置中新增“解锁密码”，验证旧密码后可以修改。
- 密码校验信息仅保存在本机，不存储明文密码，也不上传。

从正式版 v1.2.1 直接安装 `SFOBusinessTravel-v1.3.0.apk` 即可覆盖更新。沿用相同包名与固定签名，不要先卸载旧版。

解锁密码用于应用入口保护，不额外加密数据库和照片，与备份密码相互独立，无法在线找回。卸载、清除应用数据或设备丢失仍会造成数据丢失，请另行保留备份。旧 `.debug` 测试版与正式版存储独立，首次迁移仍需使用加密备份。

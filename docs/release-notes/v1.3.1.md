# SFOBusinessTravel v1.3.1

- 应用解锁和新备份使用同一个密码，不再要求另设、重复确认备份密码。
- 支持 4–128 位密码，包括 4 位数字密码。已有密码继续有效，无需重设。
- 设置中修改密码必须先验证旧密码，后续解锁和新备份立即使用新密码。
- 已导出的备份保留创建时的密码；恢复时可选择“使用旧备份的密码”，不会改变当前应用密码。
- 同版本免密重启后，首次备份操作需验证一次当前应用密码；密码只在当前会话内存中使用，不保存明文到手机存储。

正式版可直接覆盖安装 `SFOBusinessTravel-v1.3.1.apk`，保持原包名与固定签名。无需卸载，也无需导出后重新导入账目。解锁密码用于应用入口保护，备份文件使用密码加密；卸载或清除应用数据仍会删除本地记录。

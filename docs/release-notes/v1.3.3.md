# SFOBusinessTravel v1.3.3

- 设置密码、更新后解锁、修改密码及备份密码输入默认唤起数字键盘。勾选“字母 / 符号键盘”可输入复杂密码，仍支持 4–128 个字符，不修改原有密码。
- 首次使用默认开启“记录支出时同时保存到相册”。设置中可以关闭，更新保留已有开关选择；只在账目保存成功后另存凭证，相册失败不影响账目。
- 开屏说明和隐私说明同步介绍相册默认行为。
- README 改为面向用户的应用介绍、下载安装说明和快速 Q&A，开发资料移到 docs/DEVELOPMENT.md。

沿用固定签名与原包名，可直接覆盖安装 SFOBusinessTravel-v1.3.3.apk，保留密码、账目和凭证，无需卸载。

# SFOBusinessTravel v1.4.0

- 支持编辑已有账目，保留原来的记录时间与汇率；未完成的填写可暂存草稿，下次继续。
- 新记账默认留空金额，记住上次使用的币种；仅从计算器主动带入计算结果。
- 账本和会议页面更加紧凑，增大常用按钮的触控区域。
- 设置按功能分组，保留语言、主题、城市、相册及帮助入口。
- 应用更新显示下载进度，支持取消、重试和更清晰的错误提示。
- 加密备份由系统文件选择器确认保存，显示生成与保存时间，并可设置备份提醒。
- 保持竖屏、原包名和固定签名。

直接安装 `SFOBusinessTravel-v1.4.0.apk`，或在应用设置中检查更新。可覆盖正式版 v1.3.4 和测试版 v1.3.4b，保留本机账目、凭证和原密码；更新后输入原密码即可，无需卸载。

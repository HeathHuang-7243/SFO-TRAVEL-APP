# 湾区随行 · SFOBusinessTravel

一款免费开源的安卓差旅助手，为前往旧金山与湾区出差、参加会议或旅行的人准备。

随手记下开支和小票，算清汇率与小费，查看天气、景点和会议资讯。无需注册，账目和凭证保存在自己的手机上。

**[下载最新安卓安装包](https://github.com/HeathHuang-7243/SFO-TRAVEL-APP/releases/latest)** · **[提出问题或建议](https://github.com/HeathHuang-7243/SFO-TRAVEL-APP/issues/new/choose)**

## 可以做些什么？

- **记录差旅开支**：记录金额、币种、分类和备注，拍摄或选择凭证照片，查看汇总并导出 CSV。
- **换算汇率与小费**：查询参考汇率、计算小费；每笔账目保留记录时的汇率，方便日后核对。
- **安排当地活动**：查看旧金山天气、景点介绍，以及 Microsoft Ignite 会议目录并收藏感兴趣的会议。
- **兼顾不同时区**：同时查看三个城市的时间，城市可以在设置中更换。
- **按自己的习惯使用**：支持中文 / English、浅色 / 深色 / 自动主题，以及本地加密备份。

## 开始使用

1. 打开上方下载页面，展开 **Assets**，下载 `SFOBusinessTravel-v版本号.apk`。不要下载 `Source code`，那是源代码。
2. 打开 APK，按 Android 提示允许当前下载或文件管理应用安装，并完成安装。建议使用 Android 10 或更新版本。
3. 首次打开时选择语言，设置一个 **4–128 个字符的密码**，阅读使用说明后即可开始记账。

密码输入默认使用数字键盘；使用字母或符号时，勾选“字母 / 符号键盘”。新备份也使用这个密码，无需再记一套。

以后更新：进入 **设置 → 应用更新 → 检查更新**，下载后由系统确认安装。正常覆盖更新无需卸载，也无需每次导出再恢复。

## 快速 Q&A

### 免费吗？需要账号吗？

免费，无需注册，没有广告。代码公开，你可以查看源码、提出建议，或参与改进。

### 没有网络还能用吗？

可以记账、查看本地凭证，以及浏览内置景点和已经缓存的会议内容。获取最新天气、汇率和会议资讯需要联网；离线时可使用手动或已有汇率。

### 数据存在哪里？照片会进相册吗？

账目、收藏和凭证保存在手机的应用私有空间，不上传到 GitHub 或我们的服务器。

首次使用默认开启“记录支出时同时保存到相册”，可在设置中关闭。账目保存成功后，凭证会额外存到系统相册的 **SFO Travel** 文件夹；更新保留已有开关选择。相册副本可能随你自己的相册云同步设置上传，删除账目不会删除相册副本。

### 更新或换手机会丢记录吗？

使用正式版覆盖更新会保留本机数据，更新后输入原密码即可继续使用。**不要先卸载旧版。**

换手机需要先在旧手机的 **设置 → 本地备份** 导出加密备份，再传到新手机恢复。输入相同密码不会自动同步记录。卸载应用或清除应用数据会删除本地记录，请定期把备份保存到应用之外。

### 忘记密码怎么办？可以修改吗？

密码无法在线找回。输错或暂不输入只会保持锁定，不会主动删除记录。

可以在设置中修改密码，但需要验证旧密码。修改后，新备份使用新密码，之前导出的备份仍需要创建时的密码。

### APK 提示“未安装应用”怎么办？

先确认下载的是正式 Release 中的 `.apk` 文件，并重新下载排除文件不完整的情况。已有应用时可以尝试应用内“检查更新”。请保留现有应用和数据，不要通过卸载来排查。

仍无法安装时，请到 [问题反馈](https://github.com/HeathHuang-7243/SFO-TRAVEL-APP/issues/new/choose) 提供手机型号、系统版本、当前应用版本、目标版本和错误提示。不要附上密码、账目或私人凭证。

### 可以导入网页端的账目吗？

目前不能。安卓应用与网页端的数据独立，恢复入口仅支持本应用导出的加密备份。
